Study & eCRF Designer

Build forms, typed fields, codelists and a visit schedule online, with a draft → publish lifecycle that locks forms for data entry.

21 CFR Part 11 Controls

Append-only audit trail, electronic signatures, revocable audited sessions and least-privilege RBAC, with no hard deletes of regulated data.

Rights & Data Access Groups

Granular per-role permissions and data access groups scope every user to exactly the studies, sites and records they should see.

REST API + FHIR

Versioned, token-secured API for metadata, events and records. Export to CSV/JSON or exchange over FHIR, and integrate the IWRS.

Patient Matcher

An end-to-end recruitment system that parses trial protocols, queries hospital EHR systems, matches patients to eligibility criteria, and forecasts recruitment outcomes, pairing naturally with the Clinveo EDC to move eligible patients into your study.

Technology

Built on Open Standards

All Alpha CR software is built on widely-adopted open standards and frameworks, ensuring longevity, interoperability and the ability to integrate with your existing infrastructure.

Python

Core backend logic, matching engine, data processing and simulation.

Anthropic API

AI-powered natural language criteria extraction and protocol parsing.

FHIR R4

Standard healthcare data exchange, compatible with Epic, Cerner and OpenMRS.

System Dynamics

Vensim-compatible SD model for recruitment forecasting and policy simulation.

The Clinveo EDC and IWRS/RTSM application layer: audited, role-based and API-first.

PostgreSQL

Web Dashboards

Browser-based interfaces deployable on any device, with no installation required.

Desktop Apps

Privacy by Design

Federated architecture: patient data never leaves the hospital environment.

Open Source Options

Core components available open source, enabling academic and site-level deployment.
